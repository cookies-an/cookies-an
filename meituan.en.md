## Selected Project

### AI Test Pipeline Efficiency System

`2026.01 — 2026.06`　`Led design & development`　`Java` `TypeScript` `AI Agent` `CI/CD`

An AI testing agent system built to land inside a real development pipeline.

**Core idea**

Govern the uncertainty of AI with established software engineering methodology, rather than gambling on prompt tuning — that is what turns it from an AI toy into a tool that actually saves time.

**The four chronic weaknesses it targets**

| Problem | Detail |
|---|---|
| Broken chains | Tools scattered across stages, never closing the loop |
| Chaotic multi-agent collaboration | Blurred boundaries, agents overriding and blocking each other |
| Rampant hallucination, poor usability | Output you cannot trust; review costs more than it saves |
| Slow codebase reads | Unmaintainable knowledge base; context retrieval becomes the bottleneck |

**Four modules**

A systematic answer across four dimensions: **business process**, **org structure**, **quality control**, and the **efficiency foundation**.
